# Lettered

A private room for athletes. Membership by invitation or application.

## What's here

- `prototype/index.html` is a clickable prototype of the full flow. Open it in a browser. No build step.
- `docs/product.md` covers how membership, access and pricing work.
- `docs/brand.md` covers the look, voice and copy rules.
- `CLAUDE.md` is the brief for any AI agent working in this repo.

## Run it

Open `prototype/index.html` in a browser. On a desktop you get a phone frame and a screen index. On a phone it fills the screen.
